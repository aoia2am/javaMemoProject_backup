# Java Memo Project

頭の中にある考えや「やること」を自由に書き出し、
メモを整理・細分化することで
「今、自分が何をすればいいか」を分かりやすくするJava CLIアプリです。

## コンセプト

複数のやりたいこと・やるべきことを抱えていると、
それぞれのゴールが大きく曖昧なままになり、
「何から始めればよいか」を具体的な行動まで落とし込むことが難しくなります。

このアプリでは、

1. 頭の中にあることを自由に書き出す
2. メモをプロジェクトごとに整理する
3. 大きなメモを細かいメモに分解する
4. 実行順に並べる
5. 「今やること」を1つ表示する

という流れで、行動を始めやすい状態を作ります。

## 主な機能

- 自由入力した文章をメモとして保存
- 「。」「！」「？」や改行によるメモの自動分割
- 未整理メモの管理
- プロジェクトの作成・編集・削除
- プロジェクトの並び替え
- メモの作成・編集・削除
- メモの階層化
- メモの並び替え
- 「今やること」の自動表示
- 子メモ完了時の親メモ自動完了
- プロジェクト完了時のアーカイブ移動
- テキストファイルによるデータ保存

## 使用技術

- Java 17
- Java標準ライブラリ
- ArrayList
- Scanner
- ファイル入出力
- Git / GitHub
