

### 1. コンパイル

```bash
javac *.java
````

### 2. 実行

```bash
java Main
```

### Eclipseで実行する場合

1. EclipseでJavaプロジェクトを作成します。
2. `src` フォルダに各 `.java` ファイルを配置します。
3. プロジェクト直下に `data` フォルダを作成します。
4. `Main.java` を右クリックし、`Run As > Java Application` を選択します。

## 基本的な使い方

### 1. 白紙に書き出す

HOME画面から「白紙に書き出す」を選択し、
考えていることを自由に入力します。

入力内容は、

* `。`
* `！`
* `？`
* 改行

を区切りとして、1件ずつのメモに分割されます。

### 2. 未整理メモを整理する

保存された未整理メモを1件ずつ確認し、
既存のプロジェクトまたは新しいプロジェクトへ整理します。

### 3. メモを細かくする

大きなメモを選択し、
そのメモを実行するために必要な内容を子メモとして追加できます。

```text
▼ 花火する
    1. 花火できる場所を探す
    2. 花火を買う
    3. バケツを用意する
```

### 4. メモやプロジェクトを並び替える

メモは同じ階層内で順番を変更できます。

プロジェクトも並び替えることができ、
設定した順番は「今やること」の表示順にも反映されます。

### 5. 今やることを確認する

未完了のメモの中から、
実行順が最も早いメモを「今やること」として表示します。

```text
→ 1. 花火できる場所を探す
```

### 6. メモを完了する

「今やること」を完了すると、
次の未完了メモが自動的に「今やること」になります。

子メモがすべて完了すると、
親メモも自動的に完了します。

プロジェクト内のメモがすべて完了すると、
プロジェクトも完了し、アーカイブに表示されます。

## データ保存

プロジェクトとメモのデータは、
`data` フォルダ内のテキストファイルに保存されます。

```text
data/
├── projects.txt
└── memos.txt
```

アプリを終了して再起動しても、
メモ・プロジェクト・並び順・完了状態を引き継ぐことができます。

## クラス構成

### Main

アプリの起動とHOME画面のメニュー制御を担当します。

### Project

プロジェクトのデータを保持します。

### Memo

メモのデータを保持します。

### ProjectProcess

プロジェクトの作成・編集・削除・並び替えなどを担当します。

### MemoProcess

メモの作成・整理・編集・削除・細分化・並び替え・完了処理を担当します。

### FileManager

プロジェクトとメモの保存・読み込みを担当します。

### ConsoleUtil

CLI画面の共通表示を担当します。

## 工夫した点

* 最初から整理を求めず、まず自由に書き出せるようにした
* メモを親子構造にして、大きなやることを段階的に細かくできるようにした
* 階層を `1-(1)` のように表示し、親子関係を分かりやすくした
* メモ削除後に順番が自動で詰まるようにした
* メモとプロジェクトの並び替えをできるようにした
* 子メモの完了に応じて親メモを自動完了するようにした
* 「今やること」を1つだけ表示することで、次の行動を分かりやすくした
* CLI上に現在地を表示し、どの画面にいるか分かりやすくした
* テキストファイルに保存し、再起動後も状態を保持できるようにした
